# Trading Cafe Study Desk

A study companion built from the daily live streams of
[Trading Cafe India](https://www.youtube.com/@TRADINGCAFEINDIA): setups with their logged record,
concepts, day-by-day notes with chart frames, a trade log, practice modes, and a smart money course.

Chart frames are stills from the channel's public live streams, shown here for study and commentary.
All credit for the trading method goes to the channel. This is education, not financial advice.
