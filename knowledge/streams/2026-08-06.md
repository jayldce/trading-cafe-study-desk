## Concepts taught today → see `knowledge/concepts.md`
- **New: equity "cash" T+0 pilot distorting option pricing.** Regulator-mandated last-fair-price calculation uses heavy last-minute institutional cash orders; spot lurches while the option barely moves, so intraday reference levels and daily charts both got unreliable for a few days. [▶ 10:17](https://www.youtube.com/watch?v=VRl6SfYXXiQ&t=4560s)
- **New: calendar spread as an expiry-day alternative to jodi.** Sell the current (expiring) ATM CE and PE, buy the same strikes on the next expiry. Profits if spot stays inside a wide range (~1,000 pts either side) through expiry, since the current leg decays to worthless while the next-expiry leg retains time value. Margin ~₹90,000 (used to be ~₹40–45k). Taught live but **not executed** today — this is why no jodi trade appears in the log. [▶ 14:47](https://www.youtube.com/watch?v=VRl6SfYXXiQ&t=20760s)
- IV regime evidence: Sensex IV 31 (mid-morning) → 35–40 (early afternoon) on an abnormal expiry day, both sides rich simultaneously — adds a data point to the existing IV-regimes concept. [▶ 10:12](https://www.youtube.com/watch?v=VRl6SfYXXiQ&t=4320s)
- Reinforces "don't trade the first breakout candle" (concepts.md) — trade 1 above is a live, on-camera example of exactly that trap, immediately followed by the follow-up entry that worked.
- Reinforces "roll strikes when premium runs away" — CE rolled 78600→78900→78700 and PE rolled 78800→79000 through the day as strikes went too far ITM/OTM for the ~₹300 target premium.
